# 🎨 Virtual Drawing Board

A real-time virtual drawing board that allows users to draw on the screen using hand gestures.

## 📌 About

This project uses a webcam, OpenCV and MediaPipe to track the user's hand and allows them to draw digitally using their index finger.

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe

## ✨ Features

- Real-time hand detection
- Index finger tracking
- Virtual drawing on a canvas
- Webcam-based interaction
- Real-time computer vision
- Smooth drawing experience
